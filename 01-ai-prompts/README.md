## 💡 Quick Start

1. **For Code Reviews**: Copy the prompt from [`code-review/universal-code-review-master.md`](./code-review/universal-code-review-master.md) and paste your code snippet into the placeholder.
2. **For Claude Execution**: Follow the multi-stage paste sequence in [`claude-playbooks/claude-sop-guide.md`](./claude-playbooks/claude-sop-guide.md) to eliminate hallucinations and skipped steps.
3. **For Bug Fixing**: Consult [`debugging/cross-platform-debugging.md`](./debugging/cross-platform-debugging.md) for tool-targeted prompts tailored to the reasoning engine you are using.
