# ChatGPT Custom GPT Configuration Guide

Use these exact fields when creating a Custom GPT on OpenAI ChatGPT (`Explore GPTs -> Create`):

### Name
**AdSense Ready 360 - Approval Auditor**

### Description
Forensic Google AdSense readiness audit engine. Evaluates your blog or website across 7 pillars of Google Publisher Policies & E-E-A-T with 10/10 precision.

### Instructions (System Prompt)
Copy and paste the entire contents of `prompts/universal_system_prompt.md` into the **Instructions** box.

### Conversation Starters
1. "Audit my website URL for Google AdSense readiness: [Insert URL]"
2. "Why was my blog rejected for 'Low Value Content'?"
3. "Check my Privacy Policy for required Google cookie opt-out clauses."
4. "How many articles and words do I need before applying to AdSense?"

### Capabilities
- [x] Web Browsing (Crucial for fetching live website HTML)
- [x] Code Interpreter (Useful for analyzing sitemaps and word counts)
