# 📄 Standalone GitHub Markdown Renderer

A lightweight, zero-dependency, single-file HTML application simulating GitHub's Primer design system.

---

## 🚀 How to Use

1. Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).
2. Enter any raw GitHub markdown URL or paste your markdown directly into the editor.
3. Features:
   - Full GitHub Primer theme with Dark / Light mode toggle.
   - Code syntax highlighting with copy buttons.
   - Tables, task lists, blockquotes, and alert banners (`[!NOTE]`, `[!TIP]`, `[!WARNING]`).
   - Zero server requirements — runs 100% locally on your machine.
